PK-017 — Export Produk Komersial

Jangan mengubah arsitektur aplikasi.

Jangan mengubah Master Pakan.

Jangan mengubah Formula.

Jangan mengubah Stok.

Yang dikerjakan HANYA implementasi fitur Export Produk Komersial.

==================================================
TUJUAN
==================================================

Memungkinkan Admin mengekspor Living Database Produk Komersial untuk kebutuhan backup, analisis, audit, dan migrasi data.

==================================================
FITUR
==================================================

Admin dapat melakukan export:

• Seluruh Produk

• Berdasarkan Brand

• Berdasarkan Kategori

• Berdasarkan Jenis Produk

• Berdasarkan Target Ternak

• Berdasarkan Status

==================================================
FORMAT EXPORT
==================================================

Siapkan struktur agar mendukung:

• Excel (.xlsx)

• CSV

• JSON

Belum perlu membuat generator file sebenarnya.

==================================================
DATA YANG DIEKSPOR
==================================================

Minimal meliputi:

• UUID

• Brand

• Seri Produk

• Nama Produk

• Jenis Produk

• Kategori

• Target Ternak

• Fase Pemeliharaan

• Nutrisi

• Komposisi

• Kemasan

• Produsen

• Distributor

• Status

• Tanggal Dibuat

• Tanggal Diubah

==================================================
FILTER
==================================================

Admin dapat memilih:

• Produk Aktif

• Produk Arsip

• Produk Tidak Diproduksi

• Semua Produk

==================================================
LOG EXPORT
==================================================

Simpan:

• UUID Export

• Waktu

• Admin

• Jenis Export

• Jumlah Data

==================================================
LIVING DATABASE
==================================================

Export hanya membaca Living Database.

Tidak boleh mengubah data.

==================================================
YANG TIDAK BOLEH
==================================================

❌ Jangan membuat download file sebenarnya.

❌ Jangan membuat backend.

❌ Jangan mengubah modul lain.

==================================================
ACCEPTANCE CRITERIA
==================================================

✅ Struktur Export selesai.

✅ Filter Export tersedia.

✅ Log Export tersedia.

✅ Siap diintegrasikan dengan generator Excel/CSV/JSON pada tahap berikutnya.
