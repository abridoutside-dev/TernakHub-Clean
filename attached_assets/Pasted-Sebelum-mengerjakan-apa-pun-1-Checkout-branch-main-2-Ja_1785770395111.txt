1. ENDPOINT

Endpoint TIDAK BOLEH diketik manual.

Gunakan:

Account ID

+

Region

untuk membentuk endpoint otomatis.

Contoh:

https://<account_id>.r2.cloudflarestorage.com

Endpoint hanya tampil sebagai read-only.

Tambahkan opsi:

Use Custom Endpoint

Jika aktif:

Endpoint baru boleh diedit manual.

Jika Custom Domain diisi:

gunakan Custom Domain sebagai Public URL.
