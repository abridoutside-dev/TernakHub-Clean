=========================================================
ADMIN-PLATFORM-003
Platform Health — Service Configuration
=========================================================

Lanjutkan dari ADMIN-PLATFORM-002.

=========================================================
TUJUAN
=========================================================

Platform Health bukan hanya menampilkan status service.

Platform Health harus menjadi tempat Administrator
melihat DAN mengelola konfigurasi service platform.

JANGAN membuat menu baru.

JANGAN membuat halaman baru.

Gunakan halaman Platform Health yang sudah ada.

=========================================================
LAYOUT
=========================================================

Pada setiap kartu service tambahkan tombol:

Configure

Klik Configure membuka drawer atau modal mengikuti pola UI Admin yang sudah ada.

=========================================================
SERVICE 1
SUPABASE
=========================================================

Tambahkan panel konfigurasi.

Editable:

- Display Name
- Connection Timeout
- Default Query Limit
- Auto Refresh Interval

Read Only:

- Project URL
- Region
- Database Version
- Project ID

Tambahkan tombol:

- Test Connection
- Save Configuration

JANGAN membuat SQL Editor.

JANGAN membuat Database Manager.

=========================================================
SERVICE 2
OBJECT STORAGE
=========================================================

Storage resmi TernakHub adalah Cloudflare R2.

Tambahkan panel konfigurasi.

Minimal:

- Account ID
- Bucket
- Public URL / Custom Domain
- Max Upload Size
- Allowed Mime Types
- Auto Image Compression
- Auto Convert WebP
- CDN Cache TTL

Tambahkan:

- Test Connection
- Save Configuration

Status:

- healthy
- not_configured
- unreachable

=========================================================
SERVICE 3
MESSAGE QUEUE
=========================================================

Message Queue adalah service platform.

Tambahkan panel konfigurasi.

Minimal:

- Enable Queue
- Max Retry
- Retry Delay
- Batch Size
- Worker Concurrency
- Timeout

Karena belum dipakai oleh platform:

Status:

not_implemented

Bukan blocked.

JANGAN membuat queue worker.

=========================================================
SERVICE 4
AI SERVICE
=========================================================

AI Insight bukan AI Backend.

Tambahkan panel konfigurasi.

Minimal:

- Provider
- API Key
- Base URL
- Default Model
- Temperature
- Max Tokens
- Timeout
- Enable AI

Provider harus extensible.

Contoh:

- OpenAI
- Gemini
- Claude
- OpenRouter
- Ollama

Status:

not_implemented

JANGAN membuat AI Engine.

=========================================================
PERSISTENCE
=========================================================

Simpan seluruh konfigurasi menggunakan konfigurasi platform yang sesungguhnya.

JANGAN menggunakan dummy.

JANGAN menggunakan placeholder.

Jika memang diperlukan tabel konfigurasi platform agar seluruh aplikasi dapat menggunakan konfigurasi yang sama:

- buat migration Supabase
- integrasikan repository
- gunakan tabel tersebut

JANGAN menyimpan konfigurasi di local state.
