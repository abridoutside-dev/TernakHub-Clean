TASK: SP-004 (Revisi) — Tambahkan Referensi Foto Penyakit melalui Global Media

Tujuan:
Menyempurnakan halaman Detail Penyakit dengan menambahkan referensi foto penyakit menggunakan Global Media.

PENTING

- Jangan mengubah arsitektur aplikasi.
- Jangan mengubah Master Obat.
- Jangan mengubah Produk Komersial Obat.
- Jangan mengubah Stok Obat.
- Jangan mengubah Riwayat.
- Jangan membuat Modul Media.
- Fokus hanya pada penambahan referensi media pada Detail Penyakit.

==================================================
FOTO PENYAKIT
==================================================

Tambahkan section baru:

Foto Referensi Penyakit

Menampilkan:

- Foto Utama
- Placeholder apabila media belum tersedia

==================================================
SUMBER FOTO
==================================================

Jangan menggunakan:

- image_url
- image_path
- file_name
- asset_url

Gunakan relasi:

media_uuid

yang mengacu ke Global Media.

==================================================
STRUKTUR DATA
==================================================

Setiap Detail Penyakit memiliki tambahan:

- media_uuid (nullable)

Tidak menyimpan URL gambar secara langsung.

==================================================
PENGAMBILAN MEDIA
==================================================

Saat media_uuid tersedia:

Ambil gambar dari Global Media.

Saat media_uuid kosong:

Tampilkan placeholder image.

==================================================
PERSIAPAN MASA DEPAN
==================================================

Rancang agar nanti mudah dikembangkan menjadi:

- Foto Utama
- Galeri Foto
- Dokumen Pendukung
- PDF
- Video (jika suatu saat didukung)

Tanpa mengubah struktur Detail Penyakit.

==================================================
JANGAN MENAMBAHKAN
==================================================

- Upload Media
- CRUD Media
- Modul Media
- Admin Media
- Integrasi Storage

Cukup siapkan relasi media_uuid dan tampilan referensinya.

==================================================
OUTPUT
==================================================

Detail Penyakit sekarang mendukung referensi foto melalui media_uuid yang terhubung ke Global Media, tanpa menyimpan URL gambar secara langsung.
