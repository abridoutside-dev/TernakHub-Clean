MASTER AUDIT TernakHub

Mulai sekarang hentikan implementasi fitur baru.

Mulai fase MASTER END-TO-END AUDIT.

Seluruh aplikasi harus divalidasi berdasarkan USER FLOW, bukan berdasarkan build atau type-check.

Jangan menyatakan "selesai" sampai seluruh acceptance criteria flow terpenuhi.

====================================================
ATURAN
====================================================

Jangan mengejar bug satu per satu.

Telusuri seluruh flow.

Jika menemukan akar masalah,
perbaiki akar masalahnya.

Bukan gejalanya.

====================================================
AUDIT LANDING
====================================================

Pastikan:

✓ Route "/" adalah Landing.

✓ Tidak ada Dashboard.

✓ Tidak ada Workspace.

✓ Tidak ada WorkspaceProvider.

✓ Tidak ada query workspaces.

✓ Tidak ada AppShell.

====================================================
AUDIT REGISTER
====================================================

Gunakan Supabase Auth.

Validasi:

- email

- password

- duplicate email

- loading

- resend

- error handling

====================================================
AUDIT EMAIL VERIFICATION
====================================================

Pastikan:

- email terkirim

- verify berhasil

- expired

- resend

- redirect benar

====================================================
AUDIT LOGIN
====================================================

Pastikan:

- login berhasil

- session restore

- refresh browser

- invalid password

- email belum verify

- logout login lagi

====================================================
AUDIT ONBOARDING
====================================================

Hanya muncul bila:

completed_onboarding == false

Sesudah selesai:

completed_onboarding == true

Tidak boleh muncul lagi.

====================================================
AUDIT DASHBOARD
====================================================

Dashboard hanya boleh muncul bila:

✓ Login

✓ Email Verified

✓ Onboarding selesai

✓ Workspace aktif

====================================================
AUDIT LOGOUT
====================================================

Logout wajib:

- clear session

- clear workspace

- clear cache

- clear subscriptions

- redirect Landing

Back browser tidak boleh kembali Dashboard.
